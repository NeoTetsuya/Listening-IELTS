# 🎧 Listening-IELTS — Full IELTS Listening Practice Suite (Parts 1–4)

An authentic interactive IELTS listening test preparation platform featuring full practice tests for all 4 parts of the IELTS Listening exam with embedded audio players, instant answer validation, and comprehensive tapescripts.

---

## 🌟 Key Features

- **Full Coverage of Parts 1–4**:
  - **Part 1 (Everyday Social Dialogues)**: Form completion, notes, table filling (Tests 1–11).
  - **Part 2 (Monologues in Social Contexts)**: Guided tours, announcements, map labeling (Tests 1–6).
  - **Part 3 (Academic Discussions & Tutorials)**: Multiple choice, matching, sentence completion (Tests 1–6).
  - **Part 4 (Academic Monologues / Lectures)**: Summary completion, flowcharts, note-taking (Tests 1–6).
- **Embedded HTML5 Audio Player**: Seamless playback, pause, rewind, and speed controls.
- **Instant Answer Checking**: Automated scoring, error highlighting, and correct answer display.
- **Complete Tapescripts**: Full listening transcripts with key evidence highlighted.
- **Master Directory Hub (`index.html`)**: Filter tests by part and test number.
